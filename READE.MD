# 🎯 Bingo Game Bot - የቢንጎ ጨዋታ ቦት

A complete Telegram Bingo game bot with Ethiopian payment integration (Telbirr & CBE Birr). Players can buy cards, play bingo in real-time, and winners get paid instantly to their wallet.

## 📋 Features | ባህሪያት

- 🎮 **1000 Unique Bingo Cards** - Each card is randomly generated with FREE space in center
- 💰 **Ethiopian Payments** - Telbirr (*127#) and CBE Birr (*847#) integration
- 🤖 **Telegram Bot** - Full bot interface for users
- 🌐 **Web App** - Beautiful bingo game interface
- ⚡ **Real-time Gameplay** - Numbers called every 2 seconds via WebSocket
- 🏆 **Instant Winners** - Prize (90% of pool) added to wallet immediately
- 👑 **Admin Panel** - Approve payments and withdrawals
- 📱 **Mobile Friendly** - Works perfectly on all devices
- 🗣️ **Bilingual** - Supports Amharic and English
